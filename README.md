D,sygner

Book Professional Services Anytime, Anywhere

D,sygner is a modern mobile marketplace built with Expo, React Native, TypeScript, and Firebase. The platform allows customers to discover, book, and pay for professional services while enabling service providers to manage their businesses efficiently.

---

Features

Customer Features

- User registration and login
- Browse service categories
- Search for services
- View service details and pricing
- Book appointments
- Secure online payments
- Track booking status
- Receive notifications
- Review and rate services
- Manage profile and booking history

Service Provider Features

- Create and manage service listings
- Upload service images
- Manage bookings
- Accept or reject requests
- Communicate with customers
- View earnings and analytics

Admin Features

- User management
- Service moderation
- Booking management
- Payment monitoring
- Reports and analytics
- Platform notifications

Installation

Clone Repository

git clone https://github.com/Mavula06/dsygner.git
cd dsygner

Install Dependencies

npm install

Start Development Server

npx expo start

---

Build Android Application

eas build --platform android

---

Build iOS Application

eas build --platform ios

---

Environment Variables

Create a ".env" file and configure Firebase credentials:

EXPO_PUBLIC_FIREBASE_API_KEY=
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=
EXPO_PUBLIC_FIREBASE_PROJECT_ID=
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
EXPO_PUBLIC_FIREBASE_APP_ID=
